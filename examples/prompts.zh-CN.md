# 办公数据报告提示词示例

## 月度经营分析

```text
使用 $html-briefing-report 把本月的销售、订单、客单价、区域和渠道数据整理成单文件 HTML。
结论放在最前面，写清实际值、目标达成、环比同比、主要增长与下滑来源、异常项和下月行动。
风格使用 dashboard，所有数字注明周期、单位、口径和来源。
```

## 销售目标达成

```text
根据 attached 的销售明细，生成面向销售负责人的 HTML 报告。
重点比较收入、销量、客单价、目标达成、区域/产品/渠道贡献；列出前三大增长和前三大下滑；
没有负责人的行动项不要编造，全部数据引用源文件和统计周期。
```

## 预算与费用分析

```text
把预算、实际、预测和部门费用表整理成 HTML 预算分析。
先给结论，再展示实际对预算差异、固定与变动成本、一次性项目、全年预测和行动建议。
金额统一币种和精度，明确不含税或含税口径。
```

## 项目周报或复盘

```text
把项目计划、里程碑、完成情况、风险、阻塞和负责人整理成 dashboard 风格 HTML。
第一屏说明项目状态与需要决策的事项。后续只放实际进展、偏差、影响、负责人和截止日期。
```

## 客户反馈与服务分析

```text
把工单、投诉、满意度、处理时长和重复问题整理成 HTML 服务报告。
按问题类型、渠道和影响范围拆解，区分事实、原因解释和改进动作，列出高频问题与未覆盖数据。
```

## 人力与组织分析

```text
根据人员表、招聘进度和离职数据生成 HTML 组织分析。
先说明编制、在岗、缺口、招聘达成和流失情况，再按部门拆解；严禁从姓名推断性别、年龄等未提供属性。
```
