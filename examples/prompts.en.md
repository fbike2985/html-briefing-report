# Office Data Report Prompt Examples

## Monthly operating review

```text
Use $html-briefing-report to turn this month's sales, orders, average order value, region, and channel data into a single HTML report.
Lead with actuals, target attainment, month-over-month and year-over-year movement, main growth and decline drivers, exceptions, and next-month actions.
Use the dashboard style and state the period, unit, definition, and source for every metric.
```

## Sales target analysis

```text
Create a sales-leader HTML report from the attached sales detail.
Compare revenue, volume, average order value, target attainment, and product/region/channel contribution.
List the top three growth and decline drivers. Do not invent owners or actions, and keep every value tied to the source period.
```

## Budget and expense analysis

```text
Build an HTML budget report from budget, actual, forecast, and department expense tables.
Lead with actual-versus-budget variance, fixed and variable cost, one-off items, full-year forecast, and actions.
Use one currency and precision rule, and state whether values include tax.
```

## Project weekly report or review

```text
Create a dashboard-style HTML project report from milestones, delivery status, risks, blockers, owners, and due dates.
Lead with project status and decisions needed. Follow with actual progress, deviation, impact, owner, and deadline.
```

## Customer service analysis

```text
Create an HTML service report from tickets, complaints, satisfaction, handling time, and repeat issues.
Break down issue type, channel, and impact. Separate measured facts, supported explanations, and improvement actions.
```

## Workforce and organization analysis

```text
Create an HTML organization report from headcount, hiring progress, and attrition data.
Lead with approved headcount, active headcount, gap, hiring attainment, and attrition, then break down by department.
Never infer gender, age, or other attributes that are not present in the source data.
```
